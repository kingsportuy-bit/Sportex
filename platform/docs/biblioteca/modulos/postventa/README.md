# Módulo postventa

## Responsabilidad

Cerrar costos y plazos, registrar satisfacción, reclamos, recompra y seguimiento del cliente.

## Fuente/decisión

Proceso Delta y planilla operativa solicitada.

## Owner

Comercial/postventa mediante Core SPORTEX.

## Permisos

Ventas y administración; datos financieros según capacidad.

## Contrato de entrada

Pedido entregado, costos reales, fechas, incidencias, conversación y respuesta del cliente.

## Contrato de salida

Cierre, margen, cumplimiento, satisfacción, probabilidad de recompra y próxima acción.

## Persistencia

Cierres, métricas, encuestas, reclamos, causas y seguimientos.

## Auditoría

Evaluaciones manuales, inferencias IA, cambios y cierres.

## Side effects

Encuestas, recordatorios y oportunidades comerciales autorizadas.

## Workers

Seguimiento, cálculo de recompra y reportes.

## Tests

Entrega parcial, reclamo, satisfacción inferida, corrección manual y aislamiento.

## Evidencia

Campos definidos en documentación Delta; implementación pendiente.

## Rollback

Reabrir cierre mediante comando auditado sin perder métricas anteriores.

## Estado

EN_DEFINICION.

## Cierre documental

Requiere ficha de cierre, reglas de satisfacción y prueba con historial real controlado.
