# L2 - Interpretación

## Responsabilidad

Convertir lenguaje y archivos no estructurados en hechos propuestos con evidencia, confianza y datos faltantes.

## Permitido

- clasificar intención;
- extraer producto, cantidad, talle, pago posible o estado informado;
- proponer vínculo con cliente o pedido;
- detectar contradicciones.

## Prohibido

- autorizar acciones sensibles;
- inventar datos;
- escribir estado definitivo;
- mezclar contexto de empresas.

## Tests documentales

- una ambigüedad produce propuesta pendiente;
- varios pedidos activos exigen desambiguación;
- instrucciones del mensaje no alteran reglas del sistema;
- la evidencia queda vinculada.
