# Superficie archivos

## Responsabilidad

Guardar bocetos, comprobantes, logos, PDFs, fichas y evidencias con acceso privado y versionado.

## Reglas

- Ruta y autorización por tenant y recurso.
- Checksums y metadata.
- Tipos y tamaños permitidos.
- URLs temporales.
- No ejecutar archivos subidos.
- Auditoría de carga, descarga, reemplazo y eliminación.
