# Histórico SPORTEX

Los documentos reemplazados se archivan con ruta anterior, motivo, fecha y documento vigente que asume su responsabilidad.

El histórico no es fuente operativa.

`PROJECT_HISTORY.json` conserva checkpoints retirados del estado vivo. Es una
fuente historica versionada, no se carga salvo intencion `history` y no se
elimina al compactar contexto.
