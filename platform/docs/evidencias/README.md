# Evidencias SPORTEX

Cada evidencia debe indicar tarea, fecha, entorno, rama/worktree o version,
alcance, procedimiento, comandos ejecutados, resultado, pendientes y rollback.
Los datos sensibles se describen por estado o politica, nunca por valor.

Una evidencia local no prueba un deployment ni el estado actual de una
integracion. La evidencia de runtime debe quedar ligada al artefacto, entorno y
observacion exactos.
